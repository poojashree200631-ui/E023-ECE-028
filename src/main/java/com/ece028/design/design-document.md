# UPS and Inverter AMC Pricing and Service Visit Scheduler

## 1. Project Objective
The objective is to develop a Java console application for managing UPS and inverter maintenance contracts, service visits, billing and battery replacement reports.

## 2. Technologies Used
- Java 25
- Maven
- Git
- JUnit
- CSV files

## 3. Main Modules
- Model
- Pricing
- Scheduler
- Billing
- Reports
- Services
- Utilities

## 4. Business Rules
- BR-01: AMC Pricing
- BR-02: Preventive Visits
- BR-03: Breakdown Calls
- BR-04: Parts and Warranty
- BR-05: Labour Charges
- BR-06: Battery Life
- BR-07: Expired AMC

## 5. Application Type
Command-line application with a console menu.
